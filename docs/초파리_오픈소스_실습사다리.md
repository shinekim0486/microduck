## 2. 실습 사다리 (코랩, 무료, 한 칸씩)

| 단계 | 제목 | 쓰는 파일 | 학생이 하는 것 | 나오는 것 | 시간 |
|---|---|---|---|---|---|
| 1 | 뇌 지도 표 열어보기 | 주석 표 13MB | 뉴런 종류별로 세기, 좌우 세기, 후각·시각·하강·운동뉴런 개수 확인 | "수컷 초파리 뇌엔 다리 운동뉴런이 815개" 같은 문장을 내 손으로 | 20분 |
| 2 | 내 손으로 뇌 그리기 | 주석 표 | 세포체 좌표 16만 개를 3D 산점도로, 종류별 색 | 논문 그림과 같은 뇌 모양이 내 화면에 | 20분 |
| 3 | 냄새는 어디로 가나 | 연결 표 1.1GB | 후각 뉴런 하나를 골라 연결 상대 찾기 → 그 상대의 상대 → 3단계 경로 | 코 → 촉각엽 → 하강뉴런 경로가 표로 | 40분 |
| 4 | 물통 모델 돌리기 | 우리 12MB 그래프 | 100줄 물통 코드를 파이썬으로. 코 뉴런에 물 붓고 하강뉴런 발화율 보기 | 실험실 신호 흐름 띠의 숫자가 코랩에서 재현 | 60분 |
| 5 | 내 뇌 파일 만들기 | 표 3개 + build_male.py | 시냅스 문턱값 바꿔(10→20) 내 그래프 만들고 실험실에 갈아 끼우기 | "내가 만든 뇌"로 오리가 걷음 | 60분 |
| 6 | 몸 붙이기 | 4단계 코드 + 몸 | 2D 미로/여섯 다리 곤충/마이크로덕 시뮬 중 하나 | 응용 예제 완성 | 반나절~ |

1~2단계는 코딩 초보자도 됩니다(표 열고 세고 그리기). 3단계부터 강화학습 인문학 시청자가 "아, 배선을 따라간다는 게 이거구나"를 체감합니다. 4단계가 이 강의의 심장입니다.

## 4. 콘텐츠 구조 제안
**1부 (10분) 논문:** 질문(암수 차이는 어디에), 방법(현미경 7대 13개월, 44인년 검수), 결과(95% 같고 5%는 판단 중추), 공개(지도만, 코드 없음).
**2부 (20~30분) 실습:** 사다리 1~4단계를 코랩으로. 셀마다 제이가 설명. "따라 하지 않아도 됩니다."
**3부 (10분) 응용:** C(여섯 다리) 시연 + 마이크로덕 연결 원리 + E 예고.
**마무리:** 강화학습 연결 — 지도는 복사한 것, 다음은 그 위에 보상을 얹는 것(개발계획 3단계).

## 5. 실제 데이터로 1~3단계 검증 (2026-09-16, 이 맥에서 실행)
- **1단계 (0.3초):** 뉴런 166,700개. 시각엽 내부 89,403 · 중추뇌 내부 32,164 · 척수 내부 13,161 · 하강뉴런 1,314 · 척수 운동뉴런 708 + 뇌 운동뉴런 107 = **운동뉴런 815** · 후각 2,639 · 촉각엽 투사뉴런 686 · 케니언세포 4,064 · 도파민 뉴런 340. 좌우 74,235 / 74,070.
- **2단계:** 세포체 있는 뉴런 139,662개를 3D 산점도로 그리면 논문 그림과 같은 뇌 모양(양쪽 시각엽이 큰 귀처럼)이 바로 나온다. 초보자 코드 15줄.
- **3단계 (연결표 읽기 1초, 첫 로드 45초):** 왼쪽 후각 뉴런 하나(ORN_DP1m, 발효 냄새 감지 유형)에서 출발해 시냅스 10개 이상 연결만 따라간 최단 경로:
  **코(ORN_DP1m) → 촉각엽 투사뉴런(M_l2PNl20) → 하강뉴런(DNb05) → 척수 운동뉴런(Tr extensor MN, 다리 넙다리마디를 펴는 근육)** — 시냅스 3단계.
  → 영상 한 문장: "냄새에서 다리 근육까지 시냅스 세 번. 이걸 표에서 직접 찾을 수 있습니다. 이 지도가 척수까지 있어서 가능한 일입니다."
- 후각 뉴런은 세포체가 더듬이에 있어 somaSide가 비어 있음 → 좌우는 rootSide 컬럼으로 볼 것(실습 주의점).
